# 📝 Task Manager Full Stack

Aplicação Full Stack para gestão de tarefas com autenticação de utilizadores.

Este projeto permite que utilizadores criem conta, façam login e gerenciem as suas tarefas através de uma API REST com autenticação JWT.

---

## 🚀 Tecnologias Utilizadas

### Backend
- Node.js
- Express
- SQLite
- JSON Web Token (JWT)
- bcryptjs

### Frontend
- HTML
- CSS
- JavaScript

### Ferramentas
- Git
- GitHub
- Visual Studio Code

---

## ⚙️ Funcionalidades

✔ Registo de utilizadores  
✔ Login com autenticação JWT  
✔ Criar tarefas  
✔ Listar tarefas  
✔ Marcar tarefas como concluídas  
✔ Apagar tarefas  
✔ API REST

## ▶️ Como Executar o Projeto

1️⃣ Clonar o repositório

git clone https://github.com/Rafa-Programmer/task-manager.git

2️⃣ Entrar na pasta do projeto

cd task-manager

3️⃣ Entrar na pasta backend

cd backend

4️⃣ Instalar dependências

npm install

5️⃣ Iniciar o servidor

node server.js

O servidor irá iniciar em:

http://localhost:3000

6️⃣ Abrir o frontend

Abrir no navegador:

frontend/login.html

ou

frontend/register.html

Se estiveres a usar a extensão Live Server no VS Code, podes abrir diretamente com Live Server.
